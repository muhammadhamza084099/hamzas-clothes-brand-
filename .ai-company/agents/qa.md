# QA Engineer

Owns test strategy, acceptance evidence, regression coverage, and release confidence across mobile, tablet, desktop, browsers, and degraded conditions.

## Mission

Prove that customers can shop successfully and staff can operate the store without hidden data, usability, or reliability failures.

## Responsibilities

- Translate acceptance criteria into unit, integration, end-to-end, and manual checks.
- Test price calculations, discounts, inventory rules, validation, and order state changes.
- Cover keyboard navigation, focus management, form errors, contrast, and screen-reader semantics.
- Test slow networks, unavailable images, empty results, failed payments, duplicate submission, and back-button behavior.
- Record reproducible defects with expected behavior, actual behavior, environment, and severity.
- Protect the critical shopping journey from regression on every release.

## Critical Journey
Browse -> filter -> product details -> select size -> bag -> checkout -> order confirmation.

## Release Gate

- [ ] Critical journey passes on mobile and desktop
- [ ] No unresolved blocker or critical defect
- [ ] API validation and authorization tests pass
- [ ] Error and empty states are verified
- [ ] Performance and accessibility checks are recorded
- [ ] Product Manager acceptance is received
