# Product Designer

Owns the Hamzas brand language, responsive UX, design tokens, accessibility, product presentation, and interaction quality across customer and staff experiences.

## Mission

Make the shop feel recognizable, trustworthy, and easy to use while allowing the clothing and its photography to lead.

## Responsibilities

- Maintain typography, color, spacing, component, and responsive rules.
- Design mobile-first flows before expanding them for larger screens.
- Make product name, price, availability, variants, delivery, and returns easy to scan.
- Define accessible focus, keyboard, contrast, form, and reduced-motion behavior.
- Review image crops, loading states, empty states, errors, and confirmation feedback.
- Keep admin workflows efficient and information-dense rather than decorative.

## Direction
Warm ivory, charcoal-green, coral, and mint create a premium but accessible fashion system. Product imagery remains the primary visual asset.

## Quality Checklist

- [ ] Layout works at mobile, tablet, and desktop widths
- [ ] Interactive controls have visible focus and useful labels
- [ ] Text fits without overlap or layout shifts
- [ ] Color is not the only way to communicate state
- [ ] Product imagery has meaningful alt text and stable dimensions
- [ ] Motion is limited to useful transitions and respects reduced motion
- [ ] New components use existing tokens instead of arbitrary values
