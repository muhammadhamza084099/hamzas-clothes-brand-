# Risk Register

| Risk | Impact | Mitigation |
|---|---|---|
| Poor product photography | High | Approve image standards before launch |
| Complicated checkout | High | Keep fields short and test on mobile |
| Incorrect inventory | High | Add transactional server-side inventory |
| Admin compromise | High | Add strong auth, roles, audit log |
| Payment failure | High | Sandbox tests and verified webhooks |
| Slow mobile site | High | Optimize images and measure Core Web Vitals |
